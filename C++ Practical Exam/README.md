# C++ Practical Exam Programs

This repository contains C++ programs demonstrating core Object-Oriented Programming (OOP) concepts as per practical exam requirements.

---

## Programs Included

### 1. Student Class
- Demonstrates parameterized constructor
- Array of objects
- Private data members
- Output of student details

### 2. Car Class
- Demonstrates Encapsulation
- Private attributes
- Getter and Setter methods

### 3. Device, Laptop, Smartphone
- Demonstrates Inheritance
- Base and Derived classes
- Abstraction using display methods

### 4. Polymorphism with Device
- Virtual function `calculateDiscount()`
- Runtime polymorphism
- Array of base class pointers

### 5. Abstract Class Animal
- Pure virtual functions
- Derived classes (Lion and Fish)
- Runtime polymorphism

---

## Concepts Covered

- Constructor
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Virtual Functions
- Abstract Class
